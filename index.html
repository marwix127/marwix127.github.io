ContractLens

Descripción:

Sistema RAG (Retrieval-Augmented Generation) para el análisis preliminar de contratos y la detección de riesgos. Permite subir un contrato para generar un análisis de los riesgos y datos clave del contrato al igual que la posibilidad de conversar con un chatbot que responde preguntas sobre el contrato apoyándose en la recuperación de fragmentos relevantes del documento.

Stack tecnológico:

Backend — Node.js + Express
- pg + extensión pgvector — Postgres con búsqueda vectorial
- pdf-parse (v2) — extracción de texto página a página
- @google/genai — embeddings, análisis y chat con Gemini
- multer — subida de archivos en memoria

Frontend — React 19 + Vite + Tailwind CSS 4
- react-pdf — visor de PDF integrado (carga diferida)

Infraestructura
- Postgres + pgvector en Railway
- Frontend en Vercel
- Variables de entorno para credenciales (.env)

Modelos (Gemini)
- Embeddings: gemini-embedding-001 (1536 dimensiones)
- Análisis y chat: gemini-3.5-flash

Stronger + IA

Descripción:

Aplicación Flutter para registrar y gestionar entrenamientos, consultar la evolución física y recibir orientación personalizada mediante Gemini. Incluye historial de sesiones, sugerencias de series basadas en entrenamientos anteriores, gráficos de progreso, seguimiento de composición corporal y un mapa de recuperación de la fatiga muscular. Los datos y ejercicios personales están aislados por usuario mediante Firebase Auth y Cloud Firestore.

Stack tecnológico:

Aplicación — Flutter + Dart 3
- provider + ChangeNotifier — gestión de estado
- go_router — navegación declarativa y rutas protegidas
- fl_chart — gráficos de volumen, peso y composición corporal
- shared_preferences — persistencia local de borradores y preferencias

Backend y datos
- Firebase Authentication — acceso mediante email
- Cloud Firestore — entrenamientos, mediciones, fatiga y ejercicios personales
- Firebase App Check — protección del acceso a los servicios

Inteligencia artificial
- Firebase AI Logic + Gemini 3.5 Flash
- Coach contextual con acceso a los entrenamientos y medidas del usuario
- Peticiones mediante el proxy de Firebase, sin exponer credenciales de Gemini en la aplicación

Calidad
- 168 tests unitarios, de widgets y de flujo, con un 85 % de cobertura
- Pruebas E2E en Android y validación de las reglas de Firestore
- Integración continua con GitHub Actions

ASL Virtual Cam Translator

Descripción:

Traductor de lenguaje de señas americano (ASL) y (próximamente LSE) en tiempo real mediante cámara virtual. Detecta gestos de la mano usando Mediapipe, los clasifica con un modelo MLP y transmite el resultado como una cámara virtual con PyVirtualCam. Proyecto en desarrollo.

Características:

- Python
- Mediapipe
- MLP (Multi-Layer Perceptron)
- PyVirtualCam
- Detección de gestos en tiempo real
- Traducción ASL a texto
- Cámara virtual integrada
